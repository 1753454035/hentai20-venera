# Hentai20 source for VeneraX

A community-maintained JavaScript source adapter for Venera / VeneraX.

## Add to VeneraX

Add this source library URL in **Source Library**:

```
https://cdn.jsdelivr.net/gh/1753454035/hentai20-venera@main/index.json
```

After refreshing the library, install **Hentai20**.

## Files

- `index.json` — source library manifest
- `hentai20.js` — source implementation

## Compatibility

- Target tested version: not yet device-tested
- Intended target: VeneraX 2.3.7
- Source API: Venera JavaScript ComicSource API

## Important notes

This is an experimental community source. Hentai20 may change its page structure, chapter markup, image hosts, or anti-bot checks. The source has been committed to GitHub, but it has **not yet been verified inside VeneraX 2.3.7**. In particular, verify that search results, comic details, chapter lists, and reader images load on your device.

If requests are blocked by a Cloudflare challenge, the source may not work until the site permits the app's network requests. Do not share session cookies or account credentials.

Use only content you are authorized to access and respect the site's terms and applicable copyright rules.
